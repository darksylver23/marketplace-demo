# Marketplace Web App — Project Showcase

A full-stack marketplace web application built with Python
(Flask + FastAPI) and MySQL.

> **Note:** The source code is private because this project is part
> of an active commercial product. Screenshots are provided to
> demonstrate the UI, features, and responsive design.

## Features
- User registration and login
- Product listings with search
- Shopping cart
- Order management
- Responsive frontend (HTML, CSS, JavaScript)
- Mobile-first layout

## Tech Stack
- Backend: Flask (web pages) + FastAPI (REST API)
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Version control: Git
